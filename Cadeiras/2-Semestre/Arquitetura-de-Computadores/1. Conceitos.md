# Sistema Operacional
## Conceito

- Não há uma definição universal, porém deve atender:
    - É responsável pela comunicação e integração entre software e hardware;
    - Aloca recursos do computador destinando-os ao processos:
        - Quanto tempo de execução na CPU um processo pode dispender;
        - A quantidade e o endereçamento de memória que ele utilizará; 
    - Gerencia a execução de programas e processos.

## Componentes Básicos

- Hardware, SO, Aplicativos, Usuários

## Objetivos de um SO

- Tornar o uso do hardware mais eficiente = menos trabalho obtido com o mesmo hardware;
- Diminuir o tempo necessário para a construção de aplicativos.


## Funcionamento
- Barramento central que contrala e compartilha = CPU, Memoria, Discos, USBs, GPU

## Inicialização do SO
- Programa que é executado durante todo o uso do compotador
    - Kernel

Porém, até o kernel deve ser inicializado:  

### **Bootstrap**:
Vem da expressão em inglês "pulling oneself up by one's bootstraps" (levantar a si mesmo puxando os cadarços das próprias botas), o que remete a um processo autocontido para inicializar algo a partir do zero.

- Conceito: É o processo/conceito global de carregar o sistema operacional na memória quando o computador é ligado ou reiniciado - abrange desde o firmware ao kernel. O código está gravado em ROM

- Função: É a sequência lógica de passos (executada do firmware ao sistema operacional) que permite que um sistema simples "se puxe para cima" até carregar um ambiente complexo e totalmente operacional.

- Onde atua: Envolve desde o hardware inicial, a instrução contida na ROM/firmware (BIOS ou UEFI), até a execução final do kernel do sistema operacional.

### **Bootloader**:
O Bootloader (ou gerenciador de inicialização) é uma ferramenta de software específica responsável por _uma das etapas do processo de bootstrap_.

- Conceito: É o programa/software incumbido de **localizar o kernel** do sistema operacional no disco (ou na rede) e **carregá-lo na memória RAM**. Fica gravado na partição /boot ou /boot/efi.

- Função: Atua como a "ponte" entre o firmware da placa-mãe (BIOS/UEFI) e o Kernel do sistema. Em muitos casos, ele também permite que você escolha qual sistema operacional deseja iniciar (Menu de Dual-Boot).

- Exemplos práticos: GRUB (usado pela maioria das distribuições Linux), systemd-boot, Windows Boot Manager, rEFInd, Limine, etc.
