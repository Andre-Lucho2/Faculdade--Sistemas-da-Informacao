# Exercícios guiados e prática interativa

### SQLBolt
Plataforma interativa voltada para iniciantes, com exercícios organizados em uma sequência didática que aborda desde consultas básicas até tópicos mais avançados.

SQLBolt  
https://sqlbolt.com/

### SQL Practice
Ambiente online com exercícios práticos de SQL e correção automática, permitindo aplicar os conceitos estudados em situações próximas às encontradas no desenvolvimento de sistemas e na análise de dados.

SQL Practice  
https://sqlbolt.com/

## Desafios e resolução de problemas

### DataLemur
Coleção de exercícios inspirados em problemas utilizados por empresas de tecnologia e análise de dados, indicada para quem deseja aprofundar seus conhecimentos em consultas SQL e resolução de problemas.

DataLemur  
https://datalemur.com/

### HackerRank SQL
Plataforma de treinamento com uma trilha específica para SQL, contendo desafios de diferentes níveis de dificuldade.

HackerRank SQL  
https://www.hackerrank.com/domains/sql

## Aprendizagem baseada em desafios

### SQL Murder Mystery
Desafio gamificado em que você assume o papel de investigador e utiliza consultas SQL para analisar evidências e solucionar um mistério. É uma forma diferente de aplicar seleção, filtros, junções e subconsultas.

SQL Murder Mystery  
https://mystery.knightlab.com/

## Recursos adicionais
DB Fiddle
Ferramenta online para criação e teste de consultas SQL em diferentes Sistemas Gerenciadores de Banco de Dados, como Oracle, PostgreSQL, MySQL e SQL Server. Pode ser utilizada para experimentação rápida e compartilhamento de exemplos.

DB Fiddle  
https://dbfiddle.uk/
